## Design Context

### Users
Hackathon judges and developers evaluating a persona-aware AI agent for the DSN×BCT competition. Secondary audience: end users querying the agent as one of four fictional Nigerian personas (Adaeze, Tunde, etc.) to get restaurant/book/product recommendations or AI-generated reviews. Usage context: demo environment on laptops, but mobile-demo scenarios are common at in-person hackathons.

### Brand Personality
Warm, editorial, precise. Three words: **grounded, cultural, intelligent.**  
The interface should feel like a thoughtful Nigerian product — not a generic AI chatbot. Emotional goal: confidence and curiosity, not sterile efficiency.

### Aesthetic Direction
- **Palette**: Vellum white base (#faf9f5), terra cotta primary (#d97757), warm sand surfaces, deep cocoa ink. Subtle warmth without being literal Afro-kitsch.
- **Typography**: Lora serif for display/headings (weight 400), Inter for UI text. Not monospace, not Inter-only.
- **Motion**: Framer Motion throughout — token streaming, staggered agent steps, spring thread transitions.
- **Surfaces**: Assistant messages flat on page (no card/bubble); user messages in warm terra cotta pill. Drawer > modal for navigation overlays.
- **Theme**: Light mode primary, dark mode supported.
- **Anti-references**: Generic ChatGPT clone aesthetics, cyan-on-dark AI look, glassmorphism, purple gradient AI branding.

### Design Principles
1. **Cultural warmth over generic polish** — every detail should feel like it belongs in this specific context, not copied from a generic AI template.
2. **Flat surfaces, not nested cards** — assistant messages live directly on the page; use borders and spacing for hierarchy, not card shadows.
3. **Mobile-first interaction, desktop-first layout** — the experience works on a phone at a hackathon demo, but breathes on a laptop.
4. **Motion with purpose** — animations communicate state (streaming, loading, step completion), never decoration.
5. **Typography does the heavy lifting** — size, weight, and spacing create hierarchy before color ever does.
